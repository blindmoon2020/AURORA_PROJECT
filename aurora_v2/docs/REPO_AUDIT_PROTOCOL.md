# پروتکل بررسی و مقایسه یک مخزن خارجی با AURORA

**ویرایش:** ۱.۰ · ۱۵ نوامبر ۲۰۲۶ · وضعیت: آماده اجرا

این سند قاعده‌های بررسی را از قبل قفل می‌کند تا نتیجه بعد از دیدن کد تنظیم نشود.

## ورودی‌های لازم

| ورودی | چرا لازم است |
|---|---|
| نشانی مخزن | بدون آن هیچ بررسی ممکن نیست |
| عمومی یا خصوصی | مخزن خصوصی نیازمند دسترسی متصل‌شده گیت‌هاب است |
| شاخه و کامیت مرجع | بررسی روی «آخرین وضعیت» شناور بی‌معناست |
| فایل مجوز (LICENSE) | تعیین می‌کند کد قابل استفاده است یا فقط ایده |

## دوازده محور مقایسه

۱. **مجوز و مالکیت** — پیش از هر چیز. MIT/Apache-2.0/BSD: استفاده با ذکر منبع مجاز. GPL/AGPL: ویروس کوپیل‌لفت، ورود به AURORA انحصاری را ممنوع می‌کند. بدون مجوز: هیچ کدی برداشته نمی‌شود، فقط ایده خوانده می‌شود.
۲. **معماری و مرزها** — آیا هسته از حاشیه جدا است؟ آیا می‌توان بخشی را برداشت بدون شکستن بقیه؟
۳. **کیفیت داده** — منبع، تاریخ، سوگیری بقا، مدیریت شکاف، نرخ خطا.
۴. **اجرای معاملات** — مدل پرشدن، اسپرد، لغزش، کارمزد، ترتیب برخورد استاپ و تارگت.
۵. **اعتبارسنجی** — آزمون خارج‌از‌نمونه، PBO، DSR، تعداد معامله، فاصله اطمینان.
۶. **مدیریت ریسک** — سقف افت، سقف مواجهه، همبستگی، اندازه پوزیشن.
۷. **هزینه واقعی** — کارمزد و اسپرد در نتایج لحاظ شده یا نه.
۸. **آزمون‌ها** — تعداد، کیفیت، آزمون‌های مرزی نه فقط مسیر خوش‌بینانه.
۹. **امنیت و داده مشتری** — رمز، ماسک شناسه، مجوز دسترسی، ثبت حسابرسی.
۱۰. **نگهداشت‌پذیری** — وابستگی، مستندسازی، قابلیت اجرا بدون محیط نویسنده.
۱۱. **نقاط قوت قابل انتقال** — الگوریتم، ساختار، ایده‌هایی که در AURORA نیست.
۱۲. **تله‌های بازده** — شارپ تورمی، انتخاب پس‌از‌واقع، اهرم پنهان، نمونه کوچک.

## قاعده شاهد

هر ادعا در گزارش باید به فایل و شماره خط ارجاع بدهد. ستاره گیت‌هاب و متن README شاهد نیستند. اگر چیزی بررسی نشد، «بررسی‌نشده» نوشته می‌شود نه «سالم».

## قاعده ورود کد

کد خارجی فقط از این مسیر وارد AURORA می‌شود: بازنویسی در قرارداد خودمان، نوشتن تست برای رفتار مورد انتظار، اجرای ۷۴۴ تست موجود، و پوش در گیت به‌عنوان یک کامیت مستقل و قابل بازگشت. کپی خام و بدون تست مجاز نیست.

## خروجی نهایی

یک جدول امتیاز در دوازده محور، سه تا پنج قوت قابل انتقال با نام فایل و خط، همان تعداد ضعف، و یک برنامه اجرایی مرحله‌به‌مرحله با کامیت‌های پیشنهادی.
