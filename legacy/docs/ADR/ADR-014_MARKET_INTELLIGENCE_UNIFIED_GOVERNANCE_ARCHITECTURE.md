# Governance Rules


1. No direct source usage without validation.

2. Every source receives reliability score.

3. Every expert receives performance score.

4. Every AI response receives confidence score.

5. All data requires provenance tracking.

6. New providers must pass registry approval.


# Source Registry


Required fields:


- Source Identity

- Source Type

- Provider

- API Availability

- Reliability Score

- Update Frequency

- Historical Accuracy

- Data Category
